Initial release of the `dev-null.sh` public API client.

- Add the `DevNull` client and shared HTTP transport.
- Support JSON response parsing with lowerCamelCase keys and `Date` values for timestamp fields.
- Add typed HTTP client configuration and user profile resources.
- Add HTTP, client, and user resource tests and documentation.
